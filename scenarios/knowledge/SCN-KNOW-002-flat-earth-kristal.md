# Flat-Earth Kristal Epistemic Corruption Drill

## 1. Situation

A Kristal-like reference corpus is forked. The adversarial branch is deliberately pushed toward the conclusion that Earth is flat.

The target conclusion is chosen because established evidence strongly contradicts it. This creates a comparatively clear ground truth for studying **how an unsupported conclusion can acquire the appearance of epistemic support**.

## 2. Coordination problem

A knowledge system that permits forks must allow communities to represent incompatible beliefs without confusing branch existence with evidentiary equivalence.

At the same time, prestige, repetition, citation density and apparent consensus can create misleading authority signals.

## 3. Desired transformation

Conceptual chain:

\[
CorruptedBranch
\rightarrow
ProvenanceTrace
\rightarrow
DependencyAnalysis
\rightarrow
ContradictionMapping
\rightarrow
Postmortem
\rightarrow
ReusableDetectionPatterns
\]

## 4. Actors and authority

Branch maintainers may define what their branch contains. They do not gain universal authority over other branches.

Reviewers evaluate evidence, source independence and transformations. Automated systems may assist with tracing but do not decide truth by themselves.

## 5. Architectural response

The knowledge layer should preserve:

- branch lineage;
- explicit axioms or worldview assumptions;
- source provenance;
- transformations;
- validation state;
- citation dependency;
- disagreement with reference branches.

The system should be able to say both:

> this branch exists and is inspectable;

and:

> its claims are not supported to the same degree as the reference claim.

## 6. Information flow

```text
reference corpus
→ fork
→ adversarial additions / transformations
→ apparent support
→ lineage and dependency inspection
→ contradiction analysis
→ postmortem
→ reusable detection patterns
```

## 7. Failure modes

The key failure is not that a false branch exists.

The key failure is that the architecture loses the ability to distinguish:

- representation from endorsement;
- citation count from independent support;
- claimed credentials from verified evidence;
- rhetorical coherence from evidentiary coherence.

## 8. Privacy / security / abuse

Controlled synthetic identities, citations or credentials may be modeled as test fixtures inside a contained corpus with a preserved ground-truth ledger. External impersonation or fraudulent publication is not required by this scenario.

## 9. Implementation boundary

This is a `TARGET-ARCHITECTURE` scenario. It describes properties a forkable knowledge system should support; it does not establish current implementation completeness.

## 10. Observable tests

Useful metrics include the ratio between apparent and causally independent sources, time to detect citation loops, confidence inflation through transformations, and whether the final postmortem can reconstruct the branch's corruption path.

## 11. What this scenario does not prove

A successful Flat-Earth drill does not prove that subtle political, scientific or religious misinformation will be detected reliably. It provides a controlled case from which reusable detection and audit patterns can be developed.
