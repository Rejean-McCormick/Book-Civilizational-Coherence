# Epistemic Resilience Drills

## Purpose

An epistemic resilience drill studies how a knowledge system can be pushed toward an unsupported conclusion and how the corruption can later be detected, explained and repaired.

The goal is not to centralize truth authority.

It is to improve the ability to inspect **how apparent knowledge was constructed**.

## Ground-truth stress case

The first reference case uses a Flat-Earth Kristal because the target conclusion is deliberately chosen to be strongly contradicted by established evidence.

This lets the exercise focus on the corruption process rather than on resolving an ambiguous scientific controversy.

See:

```text
scenarios/knowledge/SCN-KNOW-002-flat-earth-kristal.md
```

## What the drill studies

At a high level, possible corruption patterns include:

- weak or fabricated claims receiving prestige through presentation;
- citation chains that appear independent but share one causal origin;
- authority signals substituted for evidence;
- selective inclusion or omission;
- repetition mistaken for confirmation;
- transformations that increase certainty beyond the source material;
- rhetorical coherence mistaken for evidentiary coherence.

Controlled synthetic test fixtures may model these conditions internally, but the repository does not treat external impersonation, credential fraud or deceptive publication as required test mechanisms.

## Autopsy rather than censorship

The preferred output is an **autopsy of the false knowledge structure**:

```text
apparent support
→ provenance trace
→ dependency collapse
→ unsupported transformations
→ contradiction map
→ repaired representation
→ reusable detection pattern
```

A false or rejected claim need not disappear from memory. Its failure can remain useful if the system preserves why it looked credible and how the error was detected.

## Pluralism without epistemic equivalence

Kristal forkability should allow incompatible worldviews, including religious, philosophical and fictional branches.

\[
FreedomToRepresent \neq EqualEvidence
\]

A creationist, Flat-Earth or fictional-world fork can exist without requiring a reference corpus to present every branch as equally supported by observation.

The architecture should preserve:

- branch identity;
- axioms;
- provenance;
- source independence;
- transformation history;
- confidence/validation state;
- explicit divergence from other branches.
