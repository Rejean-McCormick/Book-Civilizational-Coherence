# Practice Pattern Registry

This file indexes recurring practice patterns. Reusable sociotechnical primitives remain canonical in `scenarios/PATTERN_LIBRARY.md`.

## PR01 — Civic Fire Drill

Rehearse a legitimate counterpower pathway before an actual crisis.

## PR02 — Founder Resistance Rehearsal

Use a founder-supported disputed proposition to verify that founder prestige does not substitute for evidence, rights or procedure.

## PR03 — Epistemic Corruption Autopsy

Start from an intentionally corrupted knowledge branch, trace how apparent support accumulated, then preserve the repair as learning.

## PR04 — Worldview Fork

Permit a branch to alter axioms or interpretations while preserving lineage and divergence from the reference corpus.

## PR05 — Failure-to-Memory Conversion

Do not merely correct an error. Preserve why it happened, how it was detected and which countermeasure worked.
