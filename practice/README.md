# Practice / Mastery

Civilizational Coherence distinguishes:

\[
Theory \neq Architecture \neq Narrative \neq Practice
\]

This directory develops the **Practice** layer: how people rehearse, operate, contest, repair, teach, fork and preserve the mechanisms described elsewhere in the repository.

## Core idea

A protection that exists only in documentation may fail when it is first needed.

Practice therefore includes controlled exercises that create reusable pathways before a real crisis occurs.

\[
WrittenRight \rightarrow PracticedProcedure \rightarrow ReusableCapacity
\]

A useful analogy is a fire drill:

> The drill does not predict a fire. It makes the exit path familiar before the fire exists.

## Scope

This directory currently covers:

- `FOUNDER_FALLIBILITY.md` — why founder error must be treated as expected;
- `CIVIC_RESILIENCE_DRILLS.md` — rehearsal of legitimate opposition and counterpower;
- `EPISTEMIC_RESILIENCE_DRILLS.md` — controlled study of corrupted knowledge structures;
- `CORPUS_AUTONOMY.md` — conditions under which the corpus can survive and evolve without unique founder dependence;
- `PATTERN_REGISTRY.md` — compact index of reusable practice patterns.

Detailed test cases belong in `scenarios/`.
